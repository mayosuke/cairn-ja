『Cairn（ケルン）』は、奇妙な人々、隠された宝物、そして言葉では言い表せない怪物で満たされた、暗く神秘的な森を探索するアドベンチャーゲーム[^1]です。キャラクター作成は素早く且つランダムで、冒険は緊張感に満ち、慎重な探索が報われ、戦闘は激しく命がけです。このゲームは [ヨハーイ・ガル(Yochai Gal)氏](https://newschoolrevolution.com) によって開発されました。現在は複数の版があり（サイドバーを参照）、すべての版でルールに互換性があります。
